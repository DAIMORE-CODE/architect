# «Мастерская реставрации» — бриф проекта

## Концепция
Казуальный симулятор реставрации (тактильное удовлетворение + daily loop).
Игрок чистит, собирает и полирует предметы, получает награду и пополняет музей.

- **Движок:** Godot 4.7.2, рендерер Mobile
- **Язык:** GDScript, строгая типизация, только табы
- **Платформы:** Яндекс Игры (HTML5), RuStore (Android)

## Игровой цикл
Сессия 3–5 минут: **Очистка → Сборка → Полировка → Награда**.

## Удержание
- Энергия: 5 в день (временно переопределено для тестов, см. [DECISIONS.md](./DECISIONS.md), D-006)
- Музей: коллекция отреставрированных предметов
- Ежедневная награда: 7-дневный цикл, сброс при пропуске дня

## Монетизация
- Только Rewarded-реклама.
- Opt-in, показ только в логических паузах (после сессии, на экране награды и т.п.).
- Кнопка «Удвоить монеты» на экране результата.

## Метрики (целевые, уточнить с PM)
- Средняя длина сессии: 3–5 мин
- Завершение этапа очистки: порог 95% стёртой грязи (D-013)
- Полировка: порог 95% полированных зон (D-013)
- Возврат на следующий день (D1 retention) — отслеживать через DayCycle
